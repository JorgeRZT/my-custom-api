API Keys

  

    
Keys to protect public endpoints. Every endpoint is open by default; when editing one you choose which key it requires and in which header, e.g. Authorization: Bearer <key> or X-API-Key: <key>. Only a hash is stored: the value is shown once, when you create it.

    

    

      
Copy the key now. It will not be shown again.
